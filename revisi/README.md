# Revisi — Ruang Kerja Sementara

Folder ini untuk **revisi berulang** proyek PESANTREN/IMTAQ. Artefak di sini **belum final**. Isinya boleh diperbarui atau dikosongkan setelah revisi diterima.

## Alur sederhana

1. Taruh rancangan, contoh anonim, atau patch sementara di sini.
2. Lakukan revisi sebanyak yang diperlukan. Tidak perlu membuat folder baru untuk setiap perubahan kecil.
3. Setelah hasil disepakati, arsipkan versi yang disetujui di [hasil-disetujui](../hasil-disetujui/). Jika berupa kode aplikasi, terapkan juga di direktori sumber melalui perubahan dan tes yang sah.
4. Kosongkan artefak lama jika tidak diperlukan; **pertahankan README.md ini** agar folder tetap ada di GitHub.

**Peringatan:** Repo ini **public**. Jangan menyimpan data santri/guru asli, kehadiran individu, token, password, .env, database, dump, atau backup. Gunakan hanya contoh sintetis/anonim. Menghapus file dari branch tidak menghapus riwayat Git.
