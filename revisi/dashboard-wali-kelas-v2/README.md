# Dashboard Wali Kelas IMTAQ v2

Prototipe HTML mandiri untuk meninjau alur harian wali kelas: Absensi KBM H/I/S/A, Apel Pagi, dan Kedisiplinan Seragam dengan atribut Baju/Celana/Peci.

Data pada prototipe anonim/sintetis. `localStorage` hanya simulasi browser, bukan database atau catatan kehadiran resmi. File ini tidak mengaktifkan login, otorisasi, API, atau penyimpanan operasional.

Buka `dashboard.html` langsung di browser. Implementasi backend nantinya tetap wajib memvalidasi sesi, assignment kelas, CSRF, idempotensi, audit, dan concurrency di server.
