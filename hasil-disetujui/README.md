# Hasil Disetujui — Arsip Acuan

Folder ini untuk **hasil revisi yang sudah disepakati** sebagai acuan yang stabil. Folder ini **tidak ikut dikosongkan** ketika [revisi](../revisi/) dibersihkan.

## Alur sederhana

1. Simpan hanya versi akhir **non-sensitif** yang sudah disetujui (misalnya rancangan UI anonim atau spesifikasi yang boleh dipublikasikan).
2. Beri nama versi/tanggal dan referensi commit/PR bila ada.
3. Perubahan aplikasi tetap diintegrasikan ke direktori kode sumber yang benar, dengan tes dan review. **Arsip ini bukan folder runtime/deploy dan bukan bukti release produksi.**
4. Perubahan pada artefak yang disepakati harus tercatat; jangan hapus hasil sebelumnya tanpa alasan.

**Peringatan:** Repo ini **public**. Jangan menaruh data pribadi, kredensial, token, dump, atau backup. Materi sensitif harus disimpan di luar GitHub publik.
