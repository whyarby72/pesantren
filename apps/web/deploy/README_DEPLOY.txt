IMTAQ F0 WEB - CONTROLLED PASSENGER DEPLOYMENT
===========================================
THIS IS A NONPRODUCTION DEMO. No personal data or live user accounts.

PREREQUISITES
- Node.js 24.21.0 selected at cPanel Node.js application.
- Application root: /home/afradadm/imtaq-app
- Application URL: imtaq.afradadmedia.com
- Startup file: app.js (verify this setting still matches).
- ZIP generated by a successful GitHub Actions web-build job.
- Back up original 323-byte app.js and current app root before replacing it.

CONTROLLED DEPLOY (DO NOT EXECUTE UNTIL ZIP VERIFIED AND BUILD PASSED)
1. Download the 'imtaq-passenger.zip' build artifact from the GitHub Actions
   run for the exact reviewed commit. Check SHA-256 against CI output.
2. Extract ZIP outside web document root; inspect that top level includes
   app.js, server.js, package.json, .next/, public/ (may be absent if empty).
3. Make a backup of /home/afradadm/imtaq-app. Copy only the reviewed
   distribution contents into /home/afradadm/imtaq-app (not into
   /home/afradadm/imtaq.afradadmedia.com or /public_html).
4. From Node.js panel confirm version 24.21.0, startup file app.js, mode
   Production, app root 'imtaq-app' and correct URL. Click RESTART.
5. Verify HTTPS root responds with dashboard and the four domain URLs
   /akademik, /ketahfizhan, /kesantrian and /keuangan return HTTP 200.
   Invalid URLs must return 404. Verify no real data or account is served.
6. If broken, restore the backed-up app directory and RESTART. Check
   /home/afradadm/imtaq-passenger.log without sharing secrets.

IMPORTANT
- Never run next dev in public hosting.
- Never place .env, source code, database dumps or passwords in public root.
- Any externally exposed preview needs access restrictions at hosting layer.
- No login is implemented. Visual dashboard alone does not authorize real access.
- npm install is performed by CI. Standalone runtime need not run NPM Install
  unless future deployment method changes; do not run it blindly in cPanel.
- Passenger compatibility remains NOT_RUN until manual hosting smoke test.
